## 四、提交规范（过程提交）

- **小步提交**：完成一个小节点就提交，不要攒成大提交
- **提交信息**：`类型: 描述`，写清楚这次改了什么
- **常用类型**：`docs:` 文档报告 / `feat:` 新功能 / `fix:` 修复 / `chore:` 结构配置
- **每天 push 一次**：云端留痕即过程证明
- 详细命令见 [GIT-GUIDE.md](GIT-GUIDE.md)
