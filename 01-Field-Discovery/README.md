# 01 · 实地调研 Field Discovery

阶段一的过程数据都放这里：**调研报告、照片、原始数据**。

```
01-Field-Discovery/
├── README.md      # 本说明
├── REPORT.md      # 调研报告（骨架已建好，直接往下写）
├── photos/        # 调研照片：现场环境、用户访谈、竞品场景
└── raw_data/      # 原始数据：问卷导出、访谈逐字稿、观察笔记
```

## 提交规范

- 照片先压缩：**单张 < 2MB**，否则 push 会明显变慢
- `raw_data/` 保留原始格式（.xlsx / .csv / .txt 原样存档），不要手动美化
- 每次调研结束当天提交并推送：

```bash
git add .
git commit -m "docs: 10月15日调研记录与照片"
git push
```
