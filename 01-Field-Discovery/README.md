## 同框照（必交，否则扣分）

课程要求照片须为**本人到现场、本人入镜**的认证照，证明采样真实发生：

- 课题 02：每个工况拍 1 张「本人手持手机 + 当前测试场景」照片（共 4 张）
- 课题 06：本人在 5 个采样点位各拍 1 张「本人 + 点位特征」同框照（共 5+ 张）
- 详细清单见 photos/同框照清单.md，拍完把照片放进 photos/课题02/ 与 photos/课题06/

## 提交流程（零编程门槛）

1. 打开 raw_data/ 里的 CSV 模板，按采样要求逐行填数字（Excel / WPS / 记事本均可）
2. 照片按清单拍齐，存入 photos/ 对应子文件夹
3. 在 报告/ 对应文件里写分析、贴图表（Excel 插入图表即可）、给改进方案
4. 完成后：`git add . && git commit -m "docs: 完成课题02/06 实地测评" && git push`

> 折线图、雷达图都用 Excel / WPS「插入 → 图表」完成，无需写代码。
