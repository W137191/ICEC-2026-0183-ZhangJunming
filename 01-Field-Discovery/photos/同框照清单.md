# 同框照清单（必交，否则扣分）

课程硬性要求：照片须为**本人到现场、本人入镜**的认证照，证明采样真实发生。 拍完按 课题02/、课题06/ 子文件夹放进 photos/，
文件名带点位与时段（如 06-食堂-午.jpg）。

## 课题 02 · 手机发热掉电（共 4 张）

| 编号 | 场景 | 拍摄要点 |
| --- | --- | --- |
| 02-待机 | 本人手持手机，屏幕显示电量 / 温度界面，背景为安静室内 | 脸可见 + 屏幕读数可读 |
| 02-短视频 | 本人正在刷短视频，背景可见所处环境 | 脸可见 + 正在操作手机 |
| 02-导航拍摄 | 本人手持手机导航或拍摄中，背景为户外 / 道路 | 脸可见 + 屏幕导航或录制界面 |
| 02-高帧游戏 | 本人打高帧率游戏，屏幕显示游戏画面 | 脸可见 + 游戏画面可读 |

## 课题 06 · 噪声地图（5 点位 × 早午晚，至少每点位 1 张总览同框照）

| 编号 | 点位 | 拍摄要点 | 状态 |
| --- | --- | --- | --- |
| 06-图书馆 | 本人在图书馆内，背景为书架 / 自习区 | 脸可见 + 点位特征清晰 | ⚠️ 已归档 1 张（2026-10-22 晚，二楼A区，单手自拍偏糊，建议补拍清晰的） |
| 06-食堂 | 本人在食堂，背景为就餐区 / 窗口 | 脸可见 + 场景可辨 | 待拍 |
| 06-主干道 | 本人在校园主干道，背景为道路 / 人流 | 脸可见 + 道路特征 | 待拍 |
| 06-运动场 | 本人在运动场，背景为场地 / 器材 | 脸可见 + 场地特征 | 待拍 |
| 06-实训走廊 | 本人在实训室走廊（含信通学院 431 实训室门口更佳），背景为走廊 | 脸可见 + 走廊标识 | 待拍 |

> 提示：用手机自带相机，确保光线充足、人脸和场景都拍清楚；建议同时截一张分贝 / 电量 App 的读数界面作为数据佐证。
