# 项目一 · 方案草稿（候补，未启用）

## 1. 省电三板斧

1. **外设断电控制**：用 MOSFET / 负载开关在不用时切断摄像头、传感器、LED 供电，消除静态漏电。
2. **Deep-Sleep 深度休眠**：非采集期进入 Deep-Sleep（ESP32 约 10~150 µA），由 RTC
   定时器或外部中断（PIR/按键）唤醒。
3. **时钟降频**：采集间隙把 CPU 从 240MHz 降到 80MHz，并在空闲任务 `light sleep`。

## 2. 功耗预算推导模型（待填）
- 列出各模块电流：ESP32 活跃 / Deep-Sleep / 摄像头拍照瞬间 / 传感器 / 无线发射。
- 按“每日唤醒 N 次 × 每次活跃 T 秒”估算日均功耗，对比“常驻活跃”基线，验证 ≥10× 提升。

## 3. 状态机（草图）

```text
IDLE(Deep-Sleep) --RTC定时/中断--> WAKE
WAKE --> SENSE(上电传感器/摄像头)
SENSE --> PROCESS(降频推理/打包)
PROCESS --> TX(无线发送, 可选)
TX --> POWER_OFF外设 --> IDLE
```

- 连续 24 h+ 记录电池电压/功耗 CSV，画充放电曲线。
