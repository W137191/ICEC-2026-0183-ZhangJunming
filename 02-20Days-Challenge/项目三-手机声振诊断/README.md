# 项目三 · 基于手机内置传感器的日常旋转机械/电器异常声振诊断仪

> 阶段二工坊开放式项目挑战营（8 选 1，占 60 分）· **主选项** 候补方案：见同级 `../项目一-ESP32省电/` 时间窗：
> 2026-10-23 ~ 2026-11-24（约 1 个月，强制连续多日 `process_logs/`）

## 一、选题与目标

- **材料**：智能手机（iQOO 13，自带麦克风 + 加速度计）+ 电风扇 / 吹风机 / 单车（家用）
- **目标**：采集上述设备在正常与模拟异常工况下的**声学（麦克风）**与**振动（加速度计）**信号，借助 AI 编写 FFT 频谱特征提取与分类脚本，
  实现“异常工况识别”。
- **与阶段一的关系**：阶段一已用手机完成噪声测绘与电量/温度监测 App，本项目把“手机当传感终端”的能力延伸到旋转机械故障诊断，技术栈一脉相承，
  **零新增硬件**。

## 二、5 种工况定义（× 15 组 = 75 组原始序列）

| 工况 | 设备 | 条件 | 模拟异常点 |
| --- | --- | --- | --- |
| 1 | 电风扇 | 正常·低速（1 档），扇叶平衡 | 基准 |
| 2 | 电风扇 | 异常·进风遮挡（出风口/进风口半遮挡，模拟异常） | 气流受阻 |
| 3 | 电风扇 | 高速（3 档） | 高负载 |
| 4 | 吹风机 | 冷风·高速 | 高转速气流 |
| 5 | 吹风机 | 热风·高速 | 高转速 + 发热 |

> 每组同时采：① 一段 **WAV**（麦克风，16kHz / 16bit / 单声道，约 10s）② 一段 **加速度 CSV**（手机贴设备外壳，
> ax/ay/az @100Hz，约 10s）。

## 五、采集与推进计划（评分项① 75 组 + ③ 盲测/抗噪）

> 评分项② FFT 特征代码已验证（`python src/selftest.py` 一键通过，见第六节）。下列①与③**必须真机实测，AI 无法代采**。

### 5.1 第一步：装 App
- 下载 GitHub Release `apk-latest` 的 `app-debug.apk`（阶段一自研 App，v1.6：麦克风 16kHz WAV + 加速度计 ~100Hz CSV，组号自动递增）。
- 安装到 iQOO 13，授予麦克风 / 存储权限。

### 5.2 第二步：铺满 75 组（5 工况 × 15 组）
- 每工况 15 组：同点位、同设备状态，仅更换采样时刻体现随机性（见实验方案表）。
- 每组：手机固定于设备外壳（贴近振源）→ 录 ~10s 音频 + 加速度 → 自动导出同名 `.wav`/`.csv` 到 `raw_data/工况*/`。
- 命名：App 自动命名（与 CSV 同名成对即可）；也可按实验方案手改 `设备_条件_组号_YYYYMMDD-HHMM`。
- **进度校验**：每采完一批运行 `python src/check_collected.py`，看各工况 X/15 与全局 X/75，并排查“只有 WAV 缺 CSV”等不匹配。索引表 `raw_data/采集记录索引.csv` 已预填 75 行（设备/条件常数列），采后补填日期/文件名/备注。

### 5.3 第三步：实验照（评分项①要求"实验照" + 防摆拍）
每工况至少 1 张**实验照**（记录手机贴设备布置、App 录音界面、设备与被测场景）。评分项①官方原文仅要求"实验照"，**未强制本人同框**；但建议至少有几张含本人+设备+手机同框以强化真实性（同框为非扣分硬项，可作保险）。存入 `实验照/`。

### 5.4 第四步：extract 验证特征
75 组采齐后运行 `python src/fft_features.py extract`，生成 `raw_data/features.csv`，确认音频/加速度特征均正常（逻辑同 selftest）。

### 5.5 第五步：盲测视频 + 抗噪报告（评分项③）
- 另取若干未参与训练的组，训练基线分类器（`fft_features.py train`，待实数据补全）→ 录屏预测过程与结果存 `报告/`。
- 在背景人声 / 风声下重测部分组，对比信噪比下降后准确率，给滤波 / 加窗改进结论。
- 报告已填充（真实数值）：见 `报告/盲测与抗噪报告.md`；盲测分析脚本见 `src/blindtest.py`（零依赖 numpy，分层抽样盲测 + LOOCV + 噪声注入抗噪扫描）。

### 5.6 每日
- 写 `../process_logs/YYYY-MM-DD.md`（评分“防摆拍”硬要求，连续多日）。

## 六、代码验证（FFT 特征提取）

- `src/fft_features.py` 的 `extract` 管线已用合成数据自测通过：
  - **音频**：注入 100Hz 基频 + 谐波，提取 `audio_dom_freq≈100Hz`、`centroid/rolloff/low_ratio` 均合理。
  - **加速度**：注入 x=30Hz / y=12Hz / z=8Hz 振动，提取 `acc_x/y/z_dom` 与 `acc_mag_rms` 正确。
  - **CSV 兼容性**：无表头（ax,ay,az）与含时间戳表头（t,ax,ay,az，与实验方案「含时间戳」一致）两种布局均正确解析。
- 运行方式：`python src/selftest.py`（生成临时样本 → 跑真实 extract → 断言关键特征 → 清理，不污染 raw_data）。
