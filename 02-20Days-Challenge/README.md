## 提交节奏建议

- **小步提交**：每完成一个可运行的小节点就提交一次，不要攒一周
- 提交信息写清「这次改了什么」，例：`feat: 完成首页轮播图`、`fix: 修复移动端布局错位`
- 每天结束前 `git push`，云端留痕即过程证明
